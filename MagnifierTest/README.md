# MagnifierAutomation

 UI-тест для системного приложения Windows **Лупа**.

## Что проверяется

Тест запускает `magnify.exe`, выполняет системный хоткей увеличения масштаба `Win + +` и проверяет, что значение масштаба Лупы стало больше.


## Как запустить

```powershell
dotnet test MagnifierAutomation.sln
```

Тест нужно запускать на Windows в обычной интерактивной пользовательской сессии, потому что он открывает системное desktop-приложение и отправляет реальные клавиатурные события.
